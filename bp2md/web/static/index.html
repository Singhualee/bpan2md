百度网盘凭据

这一步是让程序"以你的身份"登录网盘。它只保存在你自己电脑上的 .env 文件里，不会发到别处。

打开百度网盘
怎么拿到这个 Cookie？（点开看步骤）
  1. 点上面的按钮打开百度网盘，确保已经登录（没登录就先登录）
  2. 在键盘上按 F12，页面旁边或下方会弹出一个开发者面板
  3. 在面板顶部找到 Network（中文界面叫「网络」），点它
  4. 按 F5 刷新一下页面，下面会刷出一堆请求
  5. 随便点其中最上面的一条，右侧会出现它的详情
  6. 往下找到 Request Headers（请求标头），里面有一行叫 Cookie
  7. 把 Cookie 那一行冒号后面的整段内容复制下来（会很长，几百上千字符，正常）
  8. 粘到上面的框里，然后点下面的「保存设置」
这串东西等于你的网盘登录状态。别发给任何人、别贴到网上（包括不要贴给我）。 它只保存在你自己电脑的 .env 里。失效了就按上面步骤重新复制一次。

用哪家转写服务

推荐用「阿里云百炼」：国内直连、稳定，最便宜的模型 0.288 元/小时，而且支持区分说话人。每月还有 10 小时免费额度。

怎么拿到百炼 API Key？（点开看步骤） 打开百炼 · API-KEY 页面
  1. 需要有阿里云账号。没有的话先注册一个（注册阿里云）， 并完成实名认证
  2. 打开上面的「API-KEY 页面」。首次使用会提示开通百炼，按提示点开通即可，开通本身免费
  3. 页面右上角把地域选成「华北2（北京）」——这一点很重要：每个地域的 API Key 是彼此独立、不能混用的，要和下面对象存储的地域保持一致
  4. 点 创建 API Key，「归属账号」保持默认（阿里云账号），点确定
  5. 列表里会出现一串 sk- 开头的字符，点右边的复制图标
  6. 粘到上面的「百炼 API Key」框里
这个 Key 之后还能在同一个页面再看到、再复制，所以不用担心弄丢。 但它等同于你的账号消费权限，别公开。 免费额度：录音文件识别每月 36000 秒（10 小时），超出后按 0.288 元/小时计。

文件中转（阿里云 OSS）

百炼的服务在云端，需要能访问到你的音频，所以要先放进一个对象存储。 只有选了「阿里云百炼」才需要填这一块；选硅基流动可以跳过。

打开 OSS Bucket 列表 打开 RAM 用户管理
第 1 步：建一个 Bucket（存放中转音频用）
  1. 点上面的「打开 OSS Bucket 列表」。首次使用会提示开通 OSS 服务， 按提示开通即可，开通本身免费（只有真正存了、传了才收费）
  2. 点 创建 Bucket
  3. Bucket 名称：自己起一个，要求全球唯一、只能小写字母数字和短横线， 比如 bpan2md-你的名字-2026。这个名字稍后要填到上面的「Bucket 名称」框
  4. 地域：选「华北2（北京）」，和上面百炼 API Key 的地域保持一致。 创建后地域不能改，选错了只能删掉重建
  5. 其余选项全部保持默认，点「完成创建」
  6. 「OSS 地域地址」就填 oss-cn-beijing.aliyuncs.com （规则是 oss- + 地域代号 + .aliyuncs.com； 华北2北京的代号是 cn-beijing。选别的地域就换掉中间那段）
费用：存储约 0.12 元/GB/月。我们只放抽出来的音频（1 小时约 14MB）， 所以通常一个月几分钱甚至不到，可以忽略。视频原文件不上传。
第 2 步：创建一个 AccessKey（相当于给程序一把钥匙）

推荐用子账号（RAM 用户）：权限小、泄露了也只影响这一个桶。 怕麻烦的话最底下有主账号的捷径。

  1. 点上面的「打开 RAM 用户管理」→ 点 创建用户
  2. 登录名称填 bpan2md（显示名称随便填，可以不填）
  3. 拉到下面的 访问方式 区域，勾选 「使用永久 AccessKey 访问」
  4. 勾上后会再出现一个确认框 「我确认必须创建 AccessKey」， 也要勾上，否则「确定」按钮点不动
  5. 点确定 → AccessKey ID 和 AccessKey Secret 就在结果里自动生成好了， 立刻复制到上面的两个框里（也可以点下载保存成文件）
  6. 回到用户列表，点进 bpan2md 这个用户 → 权限管理 → 新增授权 → 搜索并勾选 AliyunOSSFullAccess → 确定。 这一步不能漏：新建的子账号默认没有任何权限， 不授权就会在上传时报「没有权限」
  7. 万一第 5 步的弹窗被你关掉了：进用户详情 → 凭证管理 → AccessKey 区域 → 创建 AccessKey。ID 以后随时能看到，Secret 看不到，只能重建一个
AccessKey Secret 只在创建时完整显示一次，关掉就再也看不到了。 请务必在弹窗还开着的时候复制走。万一漏了，把那个 AccessKey 删掉、重新建一个即可， 不会有任何损失。
不想建子账号？可以直接用主账号的：登录阿里云控制台 → 右上角头像悬停 → AccessKey → 按提示勾选风险确认 → 创建 AccessKey → 复制。 但官方不推荐：主账号 Key 权限过大，一旦泄露，整个阿里云账号（含计费）都不安全。 这个 Key 只会存在你自己电脑的 .env 里，但建议还是建个子账号。
在 OSS 控制台看到「Bucket 授权策略」「阻止公共访问」这些页面，都不用管， 直接离开。程序是拿着 AccessKey 直接上传的，不需要你在那里加任何策略； 在那里乱加策略反而可能把桶暴露给所有人。
配好之后怎么确认没问题？
  1. 点「保存设置」
  2. 切到上面的 ② 先测一测 标签页，依次点三个按钮
  3. 第 2 个按钮「网络与存储预检」免费，它会真的去连你的 Bucket。 如果桶名或地域填错了，它会直接告诉你该怎么改，例如：
    ✗ OSS 桶地域不符：桶在 oss-cn-hangzhou，请把 OSS_ENDPOINT 改成 oss-cn-hangzhou.aliyuncs.com
  4. 如果报「没有权限 / AccessDenied」，检查第 2 步里的 AliyunOSSFullAccess 是不是漏了
  5. 如果上传时报权限错误，但权限明明给全了：可能是这个 Bucket 开了 「阻止公共访问」。把上面的「音频上传后是否公开可读」改成 私有，程序会改用 7 天有效的临时链接，效果一样

或者：直接转本机上的文件（跳过网盘下载）

用百度网盘客户端把视频下到本机，再让这里直接读它—— 客户端的速度通常比脚本走网页下载快得多，而且这条路 完全不需要百度 Cookie，也不占用网盘里的中转目录。

点击后会打开 Windows 文件资源管理器。程序只读你选中的文件，不移动、不改名、更不会删。

转写结果

每个音视频会产出三样：.md 是给知识库的正文， .chunks.jsonl 是分块（喂向量库用），.result.json 是原始结果。

磁盘占用与清理

转写过程中会留下两类东西：中间文件（下载的原片、抽出来的音频、切片） 和进度账本。中间文件留着是为了重跑时不用重新下载、不用重新抽音频—— 清掉它们不影响已经生成的结果，但以后要重做同一个文件就得重新来一遍。

清理到底删了什么、留了什么？（点开看）
  • 会删掉：work/raw（从网盘下下来的原视频）、 work/audio（抽出来的 mp3）、work/segments（切片）
  • 一定保留：work/state——那是"哪些文件已经花钱转写过了"的账本。 删了它，下次会把所有文件当新的重新下载并重新计费
  • 不会被碰：output/ 里的转写结果、以及你原本的视频文件
  • work/uploads（用「拖进来」方式上传时复制的那份） 只有你点右边那个按钮才会删——它是你自己的文件
  • 想连账本一起清空（完全从头再来）：把整个 work 目录删掉即可， 但已经转写过的文件会重新计费
清理是安全的：已经出稿的文件不会因此被重新下载或重新收费。
